# Redesign from First Principles

Apply when integrating a new requirement into an existing design.

Do not bolt new requirements onto an existing design with patches and special cases. Redesign as if the requirement had been a foundational assumption from day one.

- Read all affected files and understand the current design.
- Ask: "If we were writing this from scratch with this requirement, what would we build?"
- Propagate the change consistently through types, docs, examples, and callers.
- Design the clean whole, then deliver it in small, verifiable steps.
