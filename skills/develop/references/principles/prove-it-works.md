# Prove It Works

Apply after completing any task and before declaring it done.

Verify every output by checking the real artifact directly: run the feature, inspect the actual command output or stored value, and read the full diff. Proxies (file timestamps, self-reports, cached output, or "it compiles") are not proof.

- When a check fails unexpectedly, suspect the observation method before the system.
- Script deterministic checks when possible so a reviewer or future agent can rerun the exact verification.
- Show concrete evidence (commands run and observed output) in your final reply.
