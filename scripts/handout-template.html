What is this? A folder of plain Markdown checklists ("skills") that add / commands to your AI coding assistant. No runtime binary or background service. Your assistant reads the Markdown when you run a command (only /context runs automatically).

{{SVG}}

New here? First 5 minutes

  1. Install. Clone this repo, open it in your AI assistant, and say "Read AGENTS.md and install these skills." Start a new chat.
  2. Run your first task. Start with /develop, giving your goal and a check that proves it worked (or run /develop alone and it will ask): 
    /develop Fix the crash on empty CSV rows.
Done check: pytest passes with a new test.
  3. Update or tune later. Run git pull for updates. Edit ~/.agents/develop-config.md or run /context configure to adjust cost, models, or repo guides.

Under the hood (for veterans)

Host-enforced versus prompt text. Your IDE parses only two things: skill registration (skills.json or symlinks) and SKILL.md YAML frontmatter (name, description, disable-model-invocation). Everything else is plain Markdown read by the model.

Where to poke around
  • skills/<name>/SKILL.md: all {{TOTAL_SKILLS}} slash commands
  • skills/develop/playbooks/ & references/principles/: internal recipes and rules
  • skills/develop/worker.md & config-and-subagents.md: subagents and tool map
  • skills/context/references/: UW-LOCI repo maps and language guides
Escape hatches

Set delegation_policy: single-agent to stop subagent spend, default_contexts: none to disable auto-loading, or skip /develop and invoke any SKILL.md directly.
