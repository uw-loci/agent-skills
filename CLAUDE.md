# Repository guide for Claude Code

- **Installing this skill kit into your assistant:** Follow [AGENTS.md](AGENTS.md).
- **Editing this repository (skills, docs, or handouts):** Follow the **Maintaining this repository** section at the bottom of [AGENTS.md](AGENTS.md). Rebuild `docs/handouts/agent-skills-handout.pdf` via `python scripts/build-handouts.py` (or `uv run --no-project python scripts/build-handouts.py`) and verify with `python scripts/build-handouts.py --check` before committing.
